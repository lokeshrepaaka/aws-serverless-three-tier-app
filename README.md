# AWS Serverless Three-Tier Web Application

A production-style serverless three-tier application built on AWS using Infrastructure as Code and CI/CD.

## Architecture

### Presentation Tier
- Amazon S3
- Amazon CloudFront

### Application Tier
- Amazon API Gateway
- AWS Lambda

### Data Tier
- Amazon DynamoDB

## DevOps
- Terraform
- Git
- GitHub
- GitHub Actions

## Monitoring and Security
- Amazon CloudWatch
- AWS IAM
